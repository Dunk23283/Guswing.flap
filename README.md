# 🚀 GUSTWING: ULTIMATE FLIGHT

**GUSTWING** is a high-octane, 3D cyberpunk flight simulator built with Three.js. Experience intense combat, customizable ships, and 8 unique planetary sectors.

![GUSTWING UI](https://i.imgur.com/your-screenshot-here.png)

## 🎮 Game Features
- **8 Combat Sectors**: From the volcanic mines of *Volcano* to the underwater bioluminescence of *Abyss*.
- **The Hangar**: 10 exclusive high-poly ships including the **Royal Guard** and **Gold Master**.
- **Elite Customization**: Swap laser colors and ship skins in real-time.
- **Combat Systems**: 6x Continuous Beam Lasers and Homing Tactical Missiles.
- **Glassmorphic HUD**: A premium, modular UI with animated 3D scanning grids.
- **Security**: Built-in DevTools blocking and score integrity checks.

## ⌨️ Controls
| Action | Key |
| :--- | :--- |
| **Thrust / Jump** | `W` or `Space` or `Left Click` |
| **Beam Cannons** | `Right Click (Hold)` |
| **Tactical Missiles** | `E` |
| **Sonic Overdrive** | `F` (Requires 100% Charge) |
| **System Pause** | `ESC` |

## 🛠️ Technology Stack
- **Engine**: Three.js (WebGL)
- **Styling**: Pure CSS3 with Backdrop Blurs (Glassmorphism)
- **Audio**: Web Audio API (Procedural SFX)
- **Storage**: LocalStorage for persistent ship unlocks and high scores.

## 🚀 Quick Start
1. Clone the repository.
2. Open `index.html` in any modern web browser (Google Chrome recommended).
3. Click **INITIALIZE SYSTEM** and prepare for launch.
